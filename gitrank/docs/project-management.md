# Project Management

## Labels

Recommended baseline labels:

- `bug`
- `enhancement`
- `architecture`
- `scoring`
- `security`
- `documentation`
- `infra`
- `good first issue`
- `help wanted`
- `blocked`

The canonical label set is defined in `/.github/labels.yml`.

## Milestones

Use milestones by delivery slice, not by vague time buckets.

Recommended early milestones:

- `alpha-foundation`
- `github-ingestion-v1`
- `scoring-v1`
- `public-profile-v1`
- `production-hardening`

## Versioning

Use semantic versioning once releases begin:

- breaking changes increment major
- backward-compatible features increment minor
- fixes increment patch

Before 1.0, treat minor releases as meaningful but still evolving.

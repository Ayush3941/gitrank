# Glossary

## Contribution intensity

The weighted estimate of how technically meaningful a contribution was.

## Deterministic feature

A signal derived without AI, such as changed file count, review count, or merge state.

## Score event

A recorded scoring decision for a contribution or aggregate update.

## Prompt version

The tracked version of the AI prompt used to classify a contribution.

## Repository context

Metadata about a repository that influences trust or weighting, such as activity level and review structure.

## Fairness limitation

A known way the scoring model may underweight or overweight some kinds of work.

## Public alpha

The first externally usable version with real sign-in, sync, scoring, and profile flows.

# Research Notes

This folder stores local research references used while shaping GitRank policy and copy.

## Local Files (Not Committed)

- `gitrank_research.pdf`
- `gitrank_abstract.pdf`

These files are ignored from git by design so the repository history stays focused on code and docs.

## Why This Exists

- Keep root directory clean and easier to scan.
- Keep large binary research artifacts out of normal review diffs.
- Preserve a single predictable location for optional local references.

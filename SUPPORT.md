# Support

## Before Asking for Help

Read:

- `README.md`
- `gitrank/README.md`
- `CONTRIBUTING.md`

## Where To Ask

- Bugs: use the bug report issue form.
- Feature ideas: use the feature request issue form.
- Large design changes: use the architecture proposal issue form.
- Score quality concerns: use the scoring dispute issue form.

## What Makes a Good Support Request

- exact file or service involved
- expected versus actual behavior
- reproduction steps
- logs or error output
- environment details
- whether the issue is blocking development or only informational

## Security

Do not use public issues for security reports. Use `SECURITY.md`.

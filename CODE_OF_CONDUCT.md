# Code of Conduct

GitRank is an engineering project. Collaboration here should be direct, respectful, and useful.

## Expected Behavior

- Be precise and constructive.
- Critique code, ideas, and tradeoffs without attacking people.
- Assume good intent until there is evidence otherwise.
- Keep technical disagreements evidence-based.
- Respect maintainers' time by filing actionable issues and well-scoped pull requests.
- Report security concerns privately through the process in `SECURITY.md`.

## Unacceptable Behavior

- Harassment, intimidation, or discrimination.
- Personal attacks, name-calling, or sustained hostility.
- Doxxing or sharing private information without consent.
- Spam, trolling, or deliberately disruptive behavior.
- Knowingly submitting malicious code, misleading benchmarks, or manipulative scoring changes.

## Enforcement

Maintainers may edit, hide, lock, or remove comments, issues, pull requests, and discussions that violate this policy. Repeated or severe violations can result in temporary or permanent removal from the project.

## Reporting

For conduct problems, open a private maintainer contact request using the support path in `SUPPORT.md`. For security issues, do not file a public issue; use `SECURITY.md`.
